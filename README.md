# Zen CP Workspace - Standalone

This is a standalone version of the Competitive Programming Workspace. It aggregates problems from Codeforces and AtCoder and provides an integrated environment for solving them.

## 🚀 How to Run

1. **Open the folder** in your terminal.
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Start the application**:
   ```bash
   npm start
   ```

## 🛠 Tech Stack
- **React** (Frontend)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Animations)
- **Lucide React** (Icons)
- **PrismJS** (Syntax Highlighting)

## 📁 Project Structure
- `src/CPPractice.jsx`: The core component with all the logic.
- `src/App.jsx`: Main entry point.
- `package.json`: Dependencies and scripts.
